03 — Field Manual

Get on the ground in four steps.

The server runs on Minecraft Forge 1.20.1 with a small set of required mods.

Install the CurseForge app
Download it from curseforge.com/download/app and sign in.
Import the modpack
Create a new profile on Minecraft 1.20.1 with the Forge loader, then add the required mods from our comms channel.
Launch the game
Hit play. Forge and every mod load automatically.
Connect
Multiplayer → Add server → enter nationsmp.net.
